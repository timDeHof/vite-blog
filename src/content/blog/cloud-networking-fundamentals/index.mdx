# Cloud Networking Fundamentals

Understanding cloud networking is essential for building secure, scalable applications. This guide covers the core networking concepts used in cloud environments.

## Virtual Private Cloud (VPC)

A VPC is an isolated virtual network within the cloud. It gives you complete control over your network environment.

## Key Networking Concepts

### Subnets

Subnets divide your VPC into smaller network segments:

```json
{
  "cidrBlock": "10.0.0.0/16",
  "subnets": [
    { "cidr": "10.0.1.0/24", "availabilityZone": "us-east-1a", "public": true },
    { "cidr": "10.0.2.0/24", "availabilityZone": "us-east-1b", "public": true },
    { "cidr": "10.0.10.0/24", "availabilityZone": "us-east-1a", "public": false },
    { "cidr": "10.0.20.0/24", "availabilityZone": "us-east-1b", "public": false }
  ]
}
```

### CIDR Notation

| CIDR | IPs | Use Case |
|------|-----|----------|
| /16 | 65,536 | VPC |
| /24 | 256 | Subnet |
| /28 | 16 | Small subnet |

## Load Balancing

### Types of Load Balancers

| Type | Layer | Use Case |
|------|-------|----------|
| Application LB | L7 | HTTP/HTTPS traffic |
| Network LB | L4 | TCP, UDP, high performance |
| Gateway LB | L3 | Security appliances |

## DNS and Routing

### Record Types

| Type | Purpose | Example |
|------|---------|---------|
| A | IPv4 address | example.com → 1.2.3.4 |
| AAAA | IPv6 address | example.com → ::1 |
| CNAME | Alias | api.example.com → lb.example.com |
| MX | Mail servers | example.com → mail.example.com |
| TXT | Text records | Verification, SPF |

## Security Groups

Security groups act as virtual firewalls:

```json
{
  "GroupName": "web-server-sg",
  "IpPermissions": [
    {
      "IpProtocol": "tcp",
      "FromPort": 80,
      "ToPort": 80,
      "IpRanges": [{ "CidrIp": "0.0.0.0/0" }]
    },
    {
      "IpProtocol": "tcp",
      "FromPort": 443,
      "ToPort": 443,
      "IpRanges": [{ "CidrIp": "0.0.0.0/0" }]
    },
    {
      "IpProtocol": "tcp",
      "FromPort": 22,
      "ToPort": 22,
      "IpRanges": [{ "CidrIp": "10.0.0.0/16" }]
    }
  ]
}
```

## Best Practices

1. **Use private subnets** - For databases and internal services
2. **Enable VPC flow logs** - Monitor network traffic
3. **Use security groups** - Layered network security
4. **Implement NAT** - Allow outbound without inbound exposure
5. **Use private endpoints** - Access services without internet

## Conclusion

Understanding cloud networking is fundamental for building secure, scalable applications. Master these concepts to design robust cloud architectures.
