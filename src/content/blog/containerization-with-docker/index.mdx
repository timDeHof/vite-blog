# Containerization with Docker

Docker has revolutionized how we build, ship, and run applications. This guide covers Docker fundamentals essential for cloud developers.

## What is Docker?

Docker is a platform for developing, shipping, and running applications in containers. Containers are lightweight and include everything needed to run the software.

## Your First Dockerfile

```dockerfile
# Use Node.js as base image
FROM node:18-alpine

# Set working directory
WORKDIR /app

# Copy package files
COPY package*.json ./

# Install dependencies
RUN npm ci --only=production

# Copy application code
COPY . .

# Expose port
EXPOSE 3000

# Start the application
CMD ["node", "index.js"]
```

## Essential Docker Commands

| Command | Description |
|---------|-------------|
| `docker build` | Build image from Dockerfile |
| `docker run` | Run a container |
| `docker ps` | List running containers |
| `docker images` | List local images |
| `docker logs` | View container logs |
| `docker exec` | Execute command in container |

## Best Practices

### 1. Use Multi-stage Builds

```dockerfile
# Build stage
FROM node:18 AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# Production stage
FROM node:18-alpine
WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/node_modules ./node_modules
CMD ["node", "dist/index.js"]
```

### 2. Use .dockerignore

```
node_modules
npm-debug.log
.git
.gitignore
README.md
.env
dist
coverage
```

### 3. Optimize Layer Caching

```dockerfile
# Copy dependencies first (less frequent changes)
COPY package*.json ./
RUN npm ci

# Copy source code last (more frequent changes)
COPY . .
```

### 4. Use Specific Tags

```dockerfile
# ❌ Don't use :latest
FROM node:18

# ✅ Use specific versions
FROM node:18.17.0-alpine3.18
```

## Security Best Practices

1. **Don't run as root** - Use USER directive
2. **Scan for vulnerabilities** - Use docker scan
3. **Read-only containers** - Use --read-only flag
4. **Limit capabilities** - Drop unnecessary Linux capabilities

```dockerfile
# Run as non-root user
RUN addgroup -g 1001 appgroup && \\
    adduser -u 1001 -G appgroup -D appuser
USER appuser
```
