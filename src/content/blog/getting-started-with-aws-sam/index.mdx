# Getting Started with AWS SAM

AWS Serverless Application Model (SAM) is an open-source framework for building serverless applications. It provides a simplified way to define your serverless resources.

## What is AWS SAM?

SAM is an extension of CloudFormation that makes it easier to build serverless applications. It provides:
- Shorter syntax for defining Lambda functions, API Gateway, and DynamoDB
- Local testing and debugging
- Built-in best practices
- Simplified deployment

## Quick Start

### 1. Install SAM CLI

```bash
# macOS
brew install aws-sam-cli

# Verify installation
sam --version
```

### 2. Initialize a Project

```bash
sam init --name my-app --runtime nodejs18
cd my-app
```

### 3. Project Structure

```
my-app/
├── src/
│   └── index.js        # Your Lambda function
├── tests/
│   └── unit/
│       └── test_handler.js
├── template.yaml        # SAM template
├── event.json          # Test events
└── samconfig.toml      # SAM configuration
```

## template.yaml

```yaml
AWSTemplateFormatVersion: '2010-09-09'
Transform: AWS::Serverless-2016-10-31
Description: My Serverless Application

Resources:
  HelloWorldFunction:
    Type: AWS::Serverless::Function
    Properties:
      Handler: src/index.handler
      Runtime: nodejs18
      MemorySize: 128
      Timeout: 30
      Events:
        Api:
          Type: Api
          Properties:
            Path: /hello
            Method: get

Outputs:
  ApiUrl:
    Description: API Gateway endpoint URL
    Value: !Sub "https://${ServerlessRestApi}.execute-api.${AWS::Region}.amazonaws.com/Prod/hello"
```

## Local Testing

```bash
# Invoke Lambda locally
sam local invoke HelloWorldFunction

# Start local API
sam local start-api

# Generate test event
sam local invoke HelloWorldFunction --event event.json
```

## Deployment

```bash
# Build the application
sam build

# Deploy interactively
sam deploy --guided

# Or deploy directly
sam deploy --stack-name my-app --region us-east-1
```

## Key SAM Commands

| Command | Description |
|---------|-------------|
| `sam init` | Initialize new SAM project |
| `sam build` | Build the application |
| `sam local invoke` | Invoke function locally |
| `sam local start-api` | Start local API Gateway |
| `sam deploy` | Deploy to AWS |
| `sam logs` | View CloudWatch logs |
| `sam package` | Package for deployment |

## Conclusion

AWS SAM is the fastest way to build and deploy serverless applications. Its concise syntax and built-in tools make it perfect for developers who want to focus on code, not infrastructure.
