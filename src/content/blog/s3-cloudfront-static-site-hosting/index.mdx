# S3 + CloudFront: Static Site Hosting at the Edge

Combining Amazon S3 with CloudFront creates a powerful, globally distributed static site infrastructure. This guide covers everything you need to deploy fast, secure static websites.

## Why This Architecture?

- **Global edge network** - Content delivered from 600+ locations
- **Cost-effective** - Pay only for what you use
- **High availability** - 99.99% uptime SLA
- **Secure** - Built-in DDoS protection
- **Low latency** - Cache at edge locations

## Architecture Overview

```
User → CloudFront Edge → S3 Bucket
         ↓
    Route 53 (DNS)
```

## CloudFront Setup

```typescript
import { CloudFrontClient, CreateDistributionCommand } from "@aws-sdk/client-cloudfront";

const createDistribution = async () => {
  const command = new CreateDistributionCommand({
    CallerReference: `dist-${Date.now()}`,
    Comment: "Static site distribution",
    Enabled: true,
    DefaultRootObject: "index.html",
    Origins: {
      Quantity: 1,
      Items: [{
        Id: "S3-my-bucket",
        DomainName: "my-bucket.s3.amazonaws.com",
        S3OriginConfig: { OriginAccessIdentity: "" }
      }]
    },
    DefaultCacheBehavior: {
      TargetOriginId: "S3-my-bucket",
      ViewerProtocolPolicy: "redirect-to-https",
      CachePolicyId: "658327ea-f89d-4fab-a82d-5dc1ae3c9f0d"
    }
  });
  
  await client.send(command);
};
```

## Performance Optimization Tips

1. **Enable compression** - Use Brotli/Gzip
2. **Set appropriate cache headers** - Long TTL for static assets
3. **Use signed URLs** - For private content
4. **Configure error pages** - Custom 404.html
5. **Enable HTTP/2** - Better multiplexing
