# Serverless Image Processing with AWS Lambda

Image processing is a common task that can be expensive and complex. In this guide, we'll build a serverless image processing pipeline using AWS Lambda and S3.

## Architecture Overview

```
User Upload → S3 Bucket → Lambda Trigger → Process Image → Save to S3
```

## Why Serverless?

- **Cost-effective** - Pay only for processing time
- **Scalable** - Handles thousands of images automatically
- **No servers to manage** - AWS handles infrastructure
- **Fast** - Parallel processing for multiple images

## Lambda Function Code

```typescript
import { S3Client, GetObjectCommand, PutObjectCommand } from "@aws-sdk/client-s3";
import { handler } from "@aws-sdk/client-lambda";
import sharp from "sharp";

const s3 = new S3Client({});

export const handler = async (event: any) => {
  // Get the bucket name and file key from the event
  const bucket = event.Records[0].s3.bucket.name;
  const key = decodeURIComponent(event.Records[0].s3.object.key.replace(/\+/g, " "));
  
  // Download the image
  const getCommand = new GetObjectCommand({ Bucket: bucket, Key: key });
  const response = await s3.send(getCommand);
  const imageBuffer = await response.Body?.transformToByteArray();
  
  // Process the image using sharp
  const processedImage = await sharp(imageBuffer)
    .resize(800, 800, { fit: "inside", withoutEnlargement: true })
    .jpeg({ quality: 80 })
    .toBuffer();
  
  // Upload the processed image
  const outputKey = \`processed/\${key}\`;
  const putCommand = new PutObjectCommand({
    Bucket: bucket,
    Key: outputKey,
    Body: processedImage,
    ContentType: "image/jpeg"
  });
  
  await s3.send(putCommand);
  
  return { statusCode: 200, body: "Image processed successfully" };
};
```

## S3 Event Trigger Configuration

```json
{
  "LambdaFunctionConfigurations": [
    {
      "LambdaFunctionArn": "arn:aws:lambda:us-east-1:123456789012:function:image-processor",
      "Events": ["s3:ObjectCreated:*"],
      "Filter": {
        "Key": {
          "FilterRules": [
            {
              "Name": "suffix",
              "Value": ".jpg"
            },
            {
              "Name": "suffix",
              "Value": ".png"
            }
          ]
        }
      }
    }
  ]
}
```

## Processing Options

| Operation | Tool | Description |
|-----------|------|-------------|
| Resize | sharp | Scale images to specific dimensions |
| Compress | sharp | Reduce file size with quality settings |
| Thumbnail | sharp | Create multiple size variants |
| Convert | sharp | Change image format (PNG → JPEG) |
| Watermark | sharp | Add text or image overlays |

## Best Practices

1. **Use appropriate image formats** - WebP for web, JPEG for photos
2. **Set memory allocation** - More memory = faster processing
3. **Configure timeout** - Large images need more time
4. **Use destination bucket** - Keep processed images separate

## Conclusion

Serverless image processing with Lambda is cost-effective and scalable. Process thousands of images automatically without managing any servers!
